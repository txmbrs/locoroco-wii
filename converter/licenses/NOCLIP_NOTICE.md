The BLV/CLV parser and texture_format.ts are from petton-svn's LocoRoco
implementation proposed to noclip.website, pull request 893:
https://github.com/magcius/noclip.website/pull/893

The accompanying noclip.website MIT license is in LICENSE. Original authorship
comments remain in the files. Local modifications: imports use .ts extensions,
and the small Color dependency is replaced by a standalone implementation.
No original game data is included in these parser source files.
